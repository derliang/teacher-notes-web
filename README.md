# 老師隨手記 網頁版

打開就能用：<https://derliang.github.io/teacher-notes-web/>

這個 repo 只放組建好的網頁（GitHub Pages 發布用），請不要直接修改。原始碼在私有的 teacher-notes repo，用 `node web/build.js` 產生後再複製過來。

- 資料存在每位老師自己的 Google 雲端硬碟（「老師隨手記資料.xlsx」），或只存在自己的裝置上。
- 程式只申請 `drive.file` 權限，只能存取它自己建立的檔案。
